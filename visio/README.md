# Process Diagrams

This folder contains editable process-model artifacts for the Payment Exception Management System.

| File | Purpose |
|---|---|
| `PaymentExceptionLifecycle.bpmn` | BPMN 2.0 model covering detection, validation, routing, investigation, escalation, resolution, and closure. |
| `PaymentReconciliation.bpmn` | BPMN 2.0 model covering automatic matching, variance investigation, manual match or override approval, and linked exception creation. |
| `BPMN.vsdx` | Reserved Visio placeholder from the initial repository scaffold. |
| `ProcessFlow.vsdx` | Reserved Visio placeholder from the initial repository scaffold. |
| `SystemArchitecture.vsdx` | Reserved Visio placeholder from the initial repository scaffold. |

The `.bpmn` files use the BPMN 2.0 XML format and include diagram interchange coordinates. They can be imported into BPMN-compatible modeling tools for review and further editing. The documented Mermaid views and supporting process definition are in `documentation/BusinessProcessFlow.md`.
