## Directory overview

- `dashboard/` contains the planned frontend feature areas.
- `powerbi/` contains Power BI dashboard artifacts.
- `mock_data/` contains sample data files for development and testing.
- `visio/` contains process and architecture diagrams.
- `documentation/` contains project and user documentation.
- `jira/` contains sprint exports.
- `confluence/` contains collaboration and planning documents.
- `sharepoint/BusinessDocuments/` contains shared business documents.
